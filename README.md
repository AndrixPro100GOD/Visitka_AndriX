# Портфолио — статический сайт

Проект без сборки: откройте `index.html` в браузере или опубликуйте на [GitHub Pages](https://pages.github.com/).

Личная страница Андрея Алексеевича Кайденко, разработчика из Екатеринбурга. Тёмное оформление с крупной типографикой, иллюстрациями и анимациями от положения страницы. Опыт в TMS, ERP, Unity и менторстве дополняет схема разработки с ИИ-агентом: шесть этапов, распределение ответственности и два возврата к реализации.

Прокрутка управляет композицией первого экрана, типографической лентой, текущим этапом процесса и движением иллюстраций. Прокрутка остаётся стандартной, без перехвата колеса и искусственных пауз. Анимации можно отключить в подвале; системная настройка уменьшения движения учитывается автоматически. Основной контент, навигация и раскрывающийся опыт доступны без JavaScript.

Демо TMS показывает путь контейнера `MOGU 133767`, 40 ft, ISO 45G0: приём с автомобиля, распознавание камерой, размещение ричстакером в `Stock X1 Y1 Z1`, три суток хранения, выдача на второй автомобиль и оплата. Карточка заявки получает события площадки и закрывается автоматически после внешнего подтверждения оплаты. Сценарий длится около минуты; есть пауза, скорость 2×, выбор этапов и повтор. Вне экрана и в скрытой вкладке воспроизведение приостанавливается. При отключённых анимациях события проходят по нажатию. Тариф 1 200 ₽ в сутки и номера автомобилей условные.

## Локально

- Откройте `index.html` двойным щелчком, либо поднимите любой статический сервер в корне репозитория.

Например, с установленным Python:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://localhost:4173`. Установка npm-пакетов не требуется. Шрифт Manrope загружается с Google Fonts; без сети используется системный шрифт.

Контент находится в `index.html`, общие стили — в `index.css`, поведение — в `js/site.js`. Сценарий TMS изолирован в `js/tms-demo.js`, оформление — в `tms-demo.css`. Семь иллюстраций лежат в `images/` под именами по назначению. При замене сохраните новый JPEG с датой или версией в имени и обновите `src`, размеры и параметр `?v=...` в HTML для сброса кэша. Карта файлов и исходные промпты — в [documents/IMAGE_PROMPTS.md](./documents/IMAGE_PROMPTS.md).

## GitHub Pages

1. Загрузите репозиторий на GitHub.
2. **Settings → Pages**: источник — ветка `master`, папка **/ (root)**.
3. Главная страница должна называться `index.html`.

Подробные правила проекта — в [documents/PROJECT_RULES.md](./documents/PROJECT_RULES.md).
